1. PROJECT OVERVIEW

1. What does your project do?

It is a full-stack, autonomous multi-agent web application that acts as an intelligent academic research assistant. It takes a research topic or query from a student/researcher, automatically searches across major academic repositories (arXiv, Semantic Scholar, OpenAlex, Crossref), extracts key methodologies and findings, generates structured 6-point paper digests, creates side-by-side comparison matrices, identifies unexplored research gaps, provides a citation-grounded conversational AI chatbot, and synthesizes complete 11-section formal literature reviews exportable directly to Microsoft Word (.docx) and publication-ready PDF formats.

2. What problem does it solve?

Conducting an academic literature survey manually is time-consuming, fragmented, and mentally exhausting. Researchers often spend weeks reading hundreds of PDFs, manually extracting parameters, struggling to spot unexplored gaps across papers, and drafting literature review chapters. Existing generic AI chatbots suffer from hallucinations and lack grounding in actual academic papers. This project solves this by using specialized, coordinated AI agents with strict citation grounding and automated document synthesis.

3. Who will use this website?

Undergraduate and postgraduate engineering students, PhD research scholars, academic faculty, data scientists, and independent researchers conducting literature surveys, background research, and technical paper writing.

4. What is the main advantage of your project?

Unlike single-prompt AI tools, our architecture divides research tasks among specialized autonomous agents (Search, Summarization, Comparison, Gap Analysis, Q&A, and Review Generation) coordinated asynchronously. It features a federated academic paper aggregator with a sub-second curated fallback cache (0.06s response), strict source grounding to prevent hallucinations, and one-click export to publication-ready .docx and .pdf documents.

4. MULTI-AGENT DETAILS

• Agent 1: Research Planner Agent (planner.py): Deconstructs the user’s broad research topic into targeted academic search queries, boolean operators, and specific sub-domain exploration vectors.

• Agent 2: Academic Paper Retrieval Agent (retrieval.py & academic_search.py): Queries external academic repositories concurrently, normalizes metadata (title, authors, year, abstract, DOI, citations), and eliminates duplicates.

• Agent 3: Paper Summarization Agent (summarizer.py): Analyzes individual papers and produces a structured 6-point analytical digest.

• Agent 4: Paper Comparison Agent (comparator.py): Aligns multiple selected papers against standard benchmark axes to generate a structured comparison matrix.

• Agent 5: Research Gap Analysis Agent (gap_analyzer.py): Identifies unresolved challenges, algorithmic weaknesses, and unexplored hybrid research directions across the gathered paper corpus.

• Agent 6: Grounded Q&A / Chatbot Agent (qa_agent.py): Provides context-aware conversational answers grounded strictly in retrieved papers with exact citations.

• Agent 7: Literature Review Generation Agent (literature_review.py): Synthesizes a formal 11-section academic literature review draft.

• Multi-Agent Coordinator (coordinator.py): Coordinates inter-agent message passing, manages async worker tasks, maintains session status in SQLite, and streams progress updates (0–100%) to the frontend.
